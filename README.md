Bootstrap Dashboard

A simple and responsive dashboard made using HTML, CSS, Bootstrap, jQuery, and Chart.js.

Features
Responsive Bootstrap layout
Navigation bar
Sidebar menu
Dashboard statistics cards
Doughnut chart
Bar chart
Recent users table
User search using jQuery
Logout button interaction
Quick and simple design
Technologies Used
HTML5
CSS3
Bootstrap 5
jQuery
Chart.js
Bootstrap Icons
Project Structure
bootstrap-dashboard/
│
├── index.html
├── style.css
└── script.js
How to Run
Download or clone the project.
Open the project folder in VS Code.
Open index.html.
Right-click and select Open with Live Server.

You can also directly open index.html in a web browser.
